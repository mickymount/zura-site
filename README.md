# Zura Public Site Template

This folder is a standalone GitHub Pages template for a separate public repository.

It contains only:

- `index.html`
- `landing.css`
- `.github/workflows/github-pages.yml`

Recommended use:

1. Create a new public repository such as `receiptiq-site`.
2. Copy the contents of this folder into that repository.
3. Push to the new repository's `main` branch.
4. In GitHub repository settings, enable Pages with `GitHub Actions`.

The resulting default URL will be:

- `https://<github-user>.github.io/<repo-name>/`

That public URL can be used for provider metadata fields such as Xero's `Company or application URL`.
